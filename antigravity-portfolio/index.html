FULL-STACK JAVA & SPRING CAPSTONE PROJECT

Local Farmers Market Platform

Problem
Small local farmers lack an accessible digital solution to list seasonal harvests, update daily stock, and process community orders directly.
Solution
Engineered a layered full-stack application with a Java & Spring Boot backend, Spring Data JPA persistence, and a responsive web storefront.
Impact
Implemented end-to-end CRUD for produce, relational order management, asynchronous cart state, and mobile-responsive UI.

Farmer Inventory & REST APIs

Problem
Produce stock changes daily based on harvest, demanding strict transactional persistence to avoid overselling.
Solution
Constructed Spring Data JPA repositories, DTO models, input validation annotations, and REST controllers.
Impact
Clean separation between business logic and database access, ensuring data consistency across product updates.
Java OOP Spring Boot Hibernate MySQL RESTful API
